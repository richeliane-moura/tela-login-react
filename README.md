# 🔐 Tela de Login em React

Este é um projeto de exemplo de um sistema de autenticação em **React**, contendo componentes de **Login**, **Cadastro** e suporte a **Dark Mode**. O projeto utiliza **React Icons** para os ícones nos inputs e validação básica de formulários.
---
## 🚀 Funcionalidades

- Formulário de **Login** com validação de email e senha
- Formulário de **Cadastro** (opcional)
- **Dark Mode** toggle
- Feedback de erros nos inputs
- Reaproveitamento de componentes (`Input`, `Login`, `Cadastro`)

## 🛠 Tecnologias

- React.js (via Vite ou Create React App)
- JavaScript (ES6+)
- React Icons (`react-icons/fa`)
- CSS (modular ou global)
