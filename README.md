# 🔐 Tela de Login em React

Uma tela de login moderna desenvolvida com **React + Vite**, utilizando **React Icons** e um estilo em **Glassmorphism**.  

---

## 🚀 Tecnologias Utilizadas

- **React**
- **Vite**
- **React Icons**
- **CSS (Glassmorphism)**
- **Hooks (useState)**
